# Kana-rush

Webブラウザ上で動作するしりとりアプリです。ひとりで練習する「練習モード」と、CPUまたはオフラインの相手と対戦する「対戦モード」を実装しています。

## デプロイ先URL

https://kanarush.hinata.works

## 使用技術

- バックエンド: Deno（`server.js`）— `serveDir`で静的ファイルを配信しつつ、`Deno.serve`でAPIを実装
- フロントエンド: HTML / CSS / JavaScript（ビルドツールなし）
- 単語の実在チェック・読み変換: [Jisho.org](https://jisho.org/)が提供するエンドポイント（`/api/v1/search/words`）を利用

## 実装した機能

### 必須機能

- 直前の単語を表示し、任意の単語を入力できる
- 直前の単語の末尾と入力単語の先頭を比較し、一致していれば更新、不一致ならエラー表示
- 「ん」で終わる単語・過去に使用した単語の入力でゲーム終了
- ゲーム中・終了後にリセット可能

### 追加機能

- **初期単語のランダム決定**：開始・リセット時に初期語をランダムに選ぶ
- **実在単語チェック**：Jisho.orgのエンドポイントで実在する単語かどうかを確認
- **のばし棒・拗音の継続判定**：「バイナリー」→「り」で継続、「マリアージュ」→「ゅ」ではなく「ゆ」で継続、といった実際のしりとりのルールに沿った判定
- **漢字混じり入力への対応**：IME変換で漢字表記になった場合も、Jisho.orgで読みを引いてひらがなに正規化してから判定
- **単語履歴表示**：これまでに使った単語をチェーン形式で画面に表示
- **対戦モード**：CPU対戦・2人でのオフライン対戦を実装。HP制・時間制で、単語の文字数がそのままダメージ量になるバトル形式

## デザイン・UI面の工夫

- トップ画面でモード（練習/CPU対戦/2人対戦）を選択し、対戦画面は1画面に統一。準備・結果・決着はポップアップで重ね、画面遷移によるちらつきを抑えている
- 対戦モードはHPバー・タイマー・獲得文字数を常時表示し、単語が決まった瞬間にダメージをリアルタイム反映
- 「ん」終わり・既出語といった致命的な入力は画面中央に大きくフラッシュ表示
- 次に入力すべき頭文字をバッジで常時表示し、タップで入力欄に自動入力

## 外部APIの利用について

単語の実在チェックには、Jisho.orgが提供するエンドポイント（`/api/v1/search/words`）を利用しています。これは正式なAPIドキュメントとして公開されているものではなく、Jisho.org自身のWebフロントエンドが内部的に使用しているエンドポイントです。

Jisho.org開発者本人が[フォーラム上で言及](https://jisho.org/forum/54fefc1f6e73340b1f160000-is-there-any-kind-of-search-api)している範囲では、辞書データの一括取得は明確に禁止されている一方、単語単位の個別の問い合わせについては第三者のツール・ラッパーライブラリでの利用も許可されています。本アプリも入力1単語につき1回の問い合わせに限定しており、一括データ取得は行っていません。

## AIの活用について

Claude Codeに委託した作業は以下の通りです。

- HTML / CSS / JavaScriptのコード実装
- Denoサーバーサイドロジック（しりとり判定・API連携部分）のコード実装
- バグ修正のコード反映（例：「バイナリー」「ショー」のように「ー」や拗音で終わる
  単語の継続判定が正しく機能しない不具合に対する、正規化処理の実装）
- 対戦モードのHP制・時間制ロジックのコード実装

課題内容の解釈と実装する追加機能の選定、各不具合の発見・原因特定、
UIの方向性決定、機能ごとの動作確認は自分で行いました。
